How to view in MySQL Workbench:

  1. Open MySQL Workbench on your computer.
  2. Click on your Local instance MySQL80 connection.
  3. In the left sidebar under Schemas, right-click and click Refresh All.
  4. Expand course_registration_db → Tables.
  5. You will see all 3 tables: students, courses, and registration!
  6. Right click any table and choose "Select Rows - Limit 1000" to see live records.

Handy SQL Queries to Run in Workbench

Copy and run these directly in MySQL Workbench SQL Editor

1. Query Enrolled Courses with Student Names 
USE course_registration_db;

SELECT 
    r.registration_id,
    s.roll_no,
    CONCAT(s.first_name, ' ', s.last_name) AS student_name,
    c.course_code,
    c.course_title,
    c.credits,
    r.status,
    r.grade
FROM registration r
JOIN students s ON r.student_id = s.student_id
JOIN courses c ON r.course_id = c.course_id
WHERE r.status = 'Enrolled'
ORDER BY r.registration_id DESC;
2. Check Course Capacity & Remaining Seats 
USE course_registration_db;

SELECT 
    c.course_code,
    c.course_title,
    c.department,
    c.max_capacity,
    COUNT(r.registration_id) AS enrolled_students,
    (c.max_capacity - COUNT(r.registration_id)) AS available_seats
FROM courses c
LEFT JOIN registration r ON c.course_id = r.course_id AND r.status = 'Enrolled'
GROUP BY c.course_id;
